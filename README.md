# Tabs، Modal و Dropdown

یه پروژه‌ی تمرینی برای یادگیری کار با `classList` و Event Delegation در جاوااسکریپت خالص — بدون هیچ کتابخونه یا فریم‌ورکی.

## دمو (لینک آنلاین)

[https://ghazal-hassanabadi.github.io/Tabs-Modal-Dropdown-js/]

## این پروژه شامل چیه؟

سه بخش مستقل که تو یه صفحه‌ی واحد قرار گرفتن:

- **Tabs** — جابه‌جایی بین سه پنل اطلاعاتی HTML، CSS و JS
- **Modal** — یه پنجره‌ی پاپ‌آپ که با دکمه، کلیک روی پس‌زمینه، یا کلید Escape بسته می‌شه
- **Dropdown** — یه منوی باز/بسته‌شونده که با کلیک بیرون از خودش، خودکار بسته می‌شه

## مفاهیمی که تمرین شده

- متدهای `classList.add()`، `classList.remove()`، `classList.toggle()`
- الگوی Event Delegation (گذاشتن یه listener روی والد به‌جای چندین listener روی فرزندها)
- مدیریت حالت‌های خاص (کلیک بیرون از یه کامپوننت، رویدادهای کیبورد، کلیک‌های نامعتبر)
- متغیرهای CSS (`:root`) برای تم‌بندی
- طراحی ریسپانسیو با media query
